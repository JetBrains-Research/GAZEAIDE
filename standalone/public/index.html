GAZEAIDE · Standalone

      

        1. Try Mouse proxy and Follow my reading with Try sample conversation,
        or open a local Codex session.
2. Review setup, start recording,
        then move between code blocks.
3. Stop to inspect visits, replay
        captured source and export results.
      

      

        Find sessions → choose a local Codex conversation → Open session. Latest
        answer and Next recorded diff navigate its output. Follow new output
        refreshes it outside recording; during a recording, Refresh session
        loads new content explicitly. Files & text also accepts non-code text.
      

      

        If guided setup pauses for insufficient samples, adjust front
        lighting/seating and click Retry this target. Earlier targets remain
        while the guide is open. Do not reload or close the guide to retry; that
        discards the unfinished run. Save appears only after every target is
        collected.
      

      

        For webcam tracking, connect the camera explicitly, then calibrate and
        inspect the five independent check targets. Save a calibration only
        after reviewing its errors. Recalibrate after moving or resizing the
        window. Personalization selects a filtering preset from six training
        targets and checks it on four fresh targets; it does not learn reading
        speed.
      

      

        Gaze-assisted review prepares bounded code context after three seconds
        in a block. Choose Explain, Compare, or Review. Open the context, edit
        it and Send to Codex. Codex requires a working local CLI sign-in. Camera
        input stays local; explicitly sent prompts go through Codex. Pinned
        webcam runtime dependencies need network access.
      

      

        Pause stops attribution while keeping the camera on. Stop camera
        releases it, pauses attribution and selects Mouse proxy. Stopped
        sessions save locally. Walkthrough notes and review marks persist with
        the session. Trace annotations/pruning affect exported reports only.
        JSON schema 3 keeps original viewing visits.
      

      

        This is a research prototype. Webcam samples are estimates; mouse modes
        are proxies. Neither exposure nor dwell measures comprehension or
        completed review. No hardware-accuracy or research-benefit claim is
        made.
